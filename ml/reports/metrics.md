# MedOS priority model — evaluation report

> **Synthetic data.** The model is trained and tested on `ml/data/triage_synthetic.csv`, generated by `ml/generate_dataset.py` from the MedOS triage protocol. It is not real patient data, so these numbers show the method works; they are not clinical validation.

- Rows: 8000 (train 6400, test 1600, stratified split)
- Model: TF-IDF (1-2 grams) + standardised vitals → multinomial logistic regression
- Features: 2256 (2242 text terms + vitals); training time 0.85 s
- Trained: 2026-10-02 15:43

## Test set (all 1600 rows)

| Method | Accuracy | Macro F1 | Critical recall | Under-triage |
|---|---|---|---|---|
| ML model alone | 95.1% | 0.944 | 87.6% | 3.8% |
| Rules engine alone | 75.8% | 0.738 | 67.2% | 23.0% |
| **Rules + ML upgrade (used in MedOS)** | 96.8% | 0.964 | 98.2% | 1.6% |

## Everyday phrasings the keyword rules don't contain (871 rows)

| Method | Accuracy | Macro F1 | Critical recall | Under-triage |
|---|---|---|---|---|
| ML model alone | 95.4% | 0.949 | 88.5% | 3.8% |
| Rules engine alone | 56.7% | 0.496 | 43.6% | 41.4% |
| **Rules + ML upgrade (used in MedOS)** | 95.3% | 0.949 | 98.1% | 2.1% |

*Under-triage* = predicted less urgent than the true level (the dangerous error).

## Phrasings the model has never seen (stricter test)

The tables above test on new patients, but those patients reuse phrasings that also appear in training. Here one phrasing per condition (25 in total) was removed from training completely, a separate model was trained without them, and it was scored only on the 1174 rows that use them.

| Method | Accuracy | Critical recall |
|---|---|---|
| ML model alone | 61.8% | 58.1% |
| Rules engine alone | 69.1% | 47.9% |
| **Rules + ML upgrade** | 72.8% | 62.9% |

This is the honest measure of how well the model handles wording it was not trained on.

## How MedOS uses the model

The rules engine sets the priority first. The model gives a second opinion and may only **raise** the level, and only when it is at least 75% confident. It can never lower a priority, so a model mistake cannot push a sick patient down the queue.
